## About

I am a **Computer Science Engineering undergraduate at Delhi Technological University (DTU)** focused on building reliable, secure, and scalable software systems.

My engineering interests span **backend development, full-stack engineering, AI/ML, distributed application architecture, and product engineering**. I enjoy taking problems from system design and API architecture through implementation, optimization, security, and production-oriented engineering.

My work combines modern backend technologies such as **Node.js, Express.js, PostgreSQL, MongoDB, Redis, REST APIs, JWT, and WebSockets** with AI/ML technologies including **LangChain, LangGraph, Groq, Ollama, and ChromaDB**.

I approach projects with a product mindset: understand the problem, design the system, build robust abstractions, measure performance, secure the interfaces, and deliver something that can actually be used.
